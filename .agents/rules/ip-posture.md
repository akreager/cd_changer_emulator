# Rule: IP posture

This project reverse-engineers a commercial product and publishes the results openly. It stays factual and stays clear of copyright and trademark problems by following these rules.

- **Don't reproduce the service manuals.** Use short factual items only: signal names, part values, document numbers and page citations. Don't copy passages or figures. Describe and cite instead.
- **Never commit manuals or datasheets.** They were removed from the repository in `f71944e`. Link to a public copy instead, preferably on archive.org, and record it in [reference/README.md](../../reference/README.md).
- **Keep brand names off hardware.** Silkscreen carries no brand names; DN-KRC3006-04 Rev C removed one. The repository name is deliberately generic.
- **No implied endorsement.** No document may suggest an affiliation with, or an endorsement by, any manufacturer. The README still needs a non-affiliation and trademark disclaimer (backlog item DC-15).
- **When unsure, ask the owner** before you commit anything that reproduces third-party material.

**Why:** community projects in this space, such as the Mictronics protocol notes and szymtro's emulator on Elektroda, have been public for years by staying factual. This project follows the same approach.
